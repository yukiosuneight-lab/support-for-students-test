# 武田塾 部活引退生応援 特設サイト（部屋めぐり版）

コンテンツごとに「部屋」を作り、スクロールで部屋から部屋へ移動する形式のページです。
3Dは使わず、HTML・CSS・JavaScript（GSAP）だけで作っています。

## 部屋の構成

| 番号 | 部屋 | 内容 |
|---|---|---|
| 01 | トップ | 応援メッセージ「努力は量じゃない、“やり方”だ。」 |
| 02 | メッセージ | 武田塾からのメッセージ |
| 03 | 武田塾の応援 | 部活も、受験も欲張れ!! ／ 応援カード |
| 04 | 協賛大会 | 春・夏の協賛大会（スマホはタブで切り替え） |
| 05 | 逆転のしくみ | 4つのステップ（自動で順に点灯、タップでも選べる） |
| 06 | 実績 | 数字とグラフ |
| 07 | やり方診断 | 5問の診断（その場で結果表示） |
| 08 | 無料相談 | 申し込み（CTA） |

## 動きの仕組み

- スクロールすると、カメラが少し引いて廊下が見え、次の部屋に寄って止まります。部屋の途中で止まることはありません。
- 部屋に入ると、その部屋の演出が1回再生されます。
- ヘッダーには全メニューを表示します。1024px未満（スマホ・タブレット）は折りたたみ式で、開くと「いまここ」が表示されます。
- ヘッダー下の8つの区切りで、いまどの部屋にいるかが分かります。
- 2つ以上離れた部屋へメニューで移動するときは、紺色の幕に部屋名を出して切り替えます。
- PCでは右下のボタンや、キーボードの左右キーでも部屋を移動できます。
- `https://…/#diagnosis` のように部屋のIDを付けたURLを開くと、その部屋から始まります（SNSや広告から診断に直接案内できます）。
- 端末で「動きを減らす」を設定している人には、部屋を縦に並べた普通のページとして表示します。

部屋のID：`top` / `message` / `cheer` / `sponsor` / `method` / `results` / `diagnosis` / `consult`

## ファイル構成

```
index.html          ページ本体（文章はここを編集）
css/style.css       見た目
js/main.js          部屋の移動と演出
js/quiz.js          やり方診断（質問と結果の文章もここ）
js/vendor/          演出用ライブラリ（GSAP / ScrollTrigger）※編集不要
images/             写真（すべて仮）
favicon.svg         ブラウザのタブに出るアイコン
```

## GitHub Pages への公開

1. リポジトリのトップ画面で「Add file → Upload files」を選びます。
2. このフォルダの中身（`index.html`、`css`、`js`、`images`、`favicon.svg`、`README.md`）をまとめてドラッグします。
3. 一番下で「Commit directly to the `main` branch」を選び、**「Commit changes」を押します**。
4. 数分後に公開ページへ反映されます。

## 公開前に差し替える箇所

| 場所 | 内容 |
|---|---|
| `images/` の写真 | 同じファイル名で上書きすれば差し替わります |
| 「無料で体験する」ボタンの `href="#"` | 申し込みフォームのURL |
| 実績の数値（+14.2 / 2,480名 / 41→63） | `data-to="…"` と表示の数字を両方書き換え。差し替えるまで「※数値・実績はイメージです」は残してください |
| `js/quiz.js` の質問・結果の文章 | 実際の指導方針に合わせて調整 |
| `og:image`（コメントアウト中） | SNSでシェアされたときの画像URL（1200×630px推奨） |
