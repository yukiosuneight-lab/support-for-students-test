# 武田塾 部活引退生応援 特設サイト

部活をやり切った高校生に向けた特設ページです。
スマホで見ることを基本に作り、PCでも崩れないレイアウトにしています。

## ファイル構成

```
index.html          ページ本体（文章はここを編集）
css/style.css       見た目（色・文字・レイアウト）
js/main.js          スクロール演出
js/quiz.js          やり方診断（質問と結果の文章もここ）
js/vendor/          演出用ライブラリ（GSAP / ScrollTrigger / Lenis）※編集不要
images/             写真（すべて仮。草案画像から切り出したもの）
favicon.svg         ブラウザのタブに出るアイコン
```

## GitHub Pages への公開

1. このフォルダの中身をリポジトリの一番上の階層にアップロードします。
2. リポジトリの Settings → Pages で、公開するブランチ（例: `main`）とフォルダ（`/ (root)`）を選んで保存します。
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で表示されます。

## 公開前に差し替える箇所

| 場所 | 内容 |
|---|---|
| `images/` の写真 | 同じファイル名で上書きすれば差し替わります。PCでもきれいに見せるには横2000px程度あると安心です（下表） |
| `index.html` の `href="#"`（無料で体験する） | 申し込みフォームのURL |
| 実績の数値（+14.2 / 2,480名 / 41→63） | `index.html` の `data-to="…"` と表示の数字を両方書き換え。実際の実績に差し替えるまで「※数値・実績はイメージです」は消さないでください |
| `js/quiz.js` の `CTA_HREF` | 診断結果のボタンのリンク先（初期値はページ下部の申し込み欄） |
| `og:image`（コメントアウト中） | SNSでシェアされたときの画像URL（1200×630px推奨） |

## スクロール演出の内容

| 場所 | 演出 |
|---|---|
| トップ | 見出しが立ち上がり、手書き文字が書かれていく。スクロールすると写真がカードから画面いっぱい（PCは右半分）に広がり、サブコピーが浮かぶ |
| 武田塾からのメッセージ | 写真が中央から広がり、見出しが1文字ずつ濃くなる |
| 武田塾の応援 | スタジアム写真に奥行き。「欲張れ!!」が弾むように登場 |
| 応援カード | 画面を固定して、5競技のカードと「いけー！」「がんばれ！」の応援の声が逆方向に流れる |
| 協賛一覧 | 「全員、応援してる。」が書かれ、大会名がアイコンと一緒に順に並ぶ |
| 逆転のしくみ | 画面を固定して、赤いリングが1周しながら①〜④のステップが順に点灯 |
| 実績 | 数字がカウントアップ。グラフはスクロールに合わせて41→63と伸び、矢印が描かれる |
| やり方診断 | 5問に答えると、その場でタイプ別の結果を表示（登録不要） |
| 申し込み | 写真がゆっくり寄り、「次の試合は、受験だ。」が1文字ずつ立ち上がる |
| 全体 | 上部の赤い進捗バー／スマホ下部の「やり方診断」「無料で受験相談」ボタン |

- スマホは端末本来のスクロールのまま、PCのマウスホイールだけ慣性スクロール（Lenis）をかけています。
- 端末で「視差効果を減らす」「アニメーションを減らす」を設定している人には、演出を止めて全文をそのまま表示します。
